# Docker POC for Node.js Application

This POC demonstrates a multi-stage Dockerfile for a Node.js application, along with a docker-compose.yml file for orchestrating the app, Postgres, and Redis containers. It also includes a .dockerignore file for excluding unnecessary files and an app/server.js file with a /health endpoint.

## Files
- `Dockerfile`
- `docker-compose.yml`
- `.dockerignore`
- `app/server.js`
