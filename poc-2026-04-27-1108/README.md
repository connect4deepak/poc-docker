# Docker POC for Node.js Application

This POC includes a multi-stage Dockerfile for a Node.js application, a docker-compose.yml file for container orchestration with Postgres and Redis, a .dockerignore file for excluding unnecessary files, and a server.js file with a /health endpoint.

## Files
- `Dockerfile`
- `docker-compose.yml`
- `.dockerignore`
- `app/server.js`
